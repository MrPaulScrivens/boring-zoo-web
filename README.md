# Boring Zoo

Static site deployed to Cloudflare Pages.

These are plain pages, edited directly in Happy Studio's Site room (the Boring Zoo brand). The brand they follow is
in `../brand/`: `tokens.yaml`, `story.md`, `voice.md`, `imagery.md`.

Until 2026-11-08 the pages were generated by a `build.py` in the WobblyOtters vault. That script is retired, so
nothing overwrites an edit made here.

## Deploy

Pushing to `main` triggers an automatic Cloudflare Pages deployment.

**Cloudflare Pages settings:**
- Build command: _(none)_
- Build output directory: `/` (repo root)
